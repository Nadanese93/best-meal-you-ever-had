# The Best Meal You Ever Had

An entry for the make.fun bounty **The Best Meal You Ever Had** (2 USD prize).
The entry is a single sentence about the best meal I ever had — a stolen
moment of cold fried chicken behind the buffet at a cousin's wedding.

`main.py` writes the entry to `entry.txt` (UTF-8, one sentence, 1–200
characters, no trailing newline). It is fully deterministic: no network,
no randomness, no clock.
